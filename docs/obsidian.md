# Obsidian Integration

This application can log focus sessions directly to Obsidian using the **Local REST API** plugin. When enabled, each session is appended to a daily note so you can keep your progress alongside other notes in your vault.

## Requirements

- Obsidian with the *Local REST API* community plugin installed and running
- An API key generated by the plugin

## Configuration

1. Open the **Settings** dialog in the Pomodoro Timer.
2. Under **Obsidian**, check **Enable Obsidian integration**.
3. Enter the REST API details:
   - **API key**: the key from the plugin settings.
   - **Endpoint**: base URL (usually `https://localhost`).
   - **Port**: port configured in the plugin (default `27123`).
   - **Log folder**: folder inside your vault where session notes are stored.
4. Save the settings.

## How It Works

- Each focus session is recorded in a markdown table within a note named `YYYY-MM-DD - Focus sessions.md` inside the chosen folder.
- Columns include start time, end time, focus text, total duration (excluding pauses) and session status (`completed` or `failed`).
- If the application is closed while a session is active, it will be logged with status `failed`.
- When Obsidian integration is disabled, sessions are written to `pomodoro_sessions.log` instead.

For general usage of the timer see the main [README](../README.md).
